# Codex Usage Widget v0.4.0

- Live five-hour reset countdown (`HH:mm:ss`) in the center of both full and compact rings.
- The countdown refreshes every second; an unknown reset shows `--:--:--`, and an elapsed reset stays at `00:00:00` until authoritative quota data updates.
- Tooltips use the same dark surface, outline, rounded corners and Segoe typography as the widget.
- Dialog placement uses XAML `CenterOwner`; standalone windows use `CenterScreen`. The main widget restores a saved position.
- Double-click anywhere on the compact surface to expand it.
- Tray menu contains Show, Full/compact, Settings and Exit. Reset and manual refresh remain in the expanded widget.
- One PowerShell release command runs English UI checks, core regressions, both packages, package smoke checks, checksums, optional Git commit/tag/push and GitHub release upload.
- Routine verification does not run every language. GitHub actions require an explicitly authorized `-Publish` invocation.

## Downloads

- `CodexUsageWidget-win-x64.zip`: Portable, with the compressed .NET runtime included.
- `CodexUsageWidget-win-x64-lite.zip`: Lite, requires Microsoft .NET 10 Desktop Runtime (Windows x64).
- Both ZIPs have SHA-256 checksum files. Extract the archive before launching the executable. Codex CLI must be installed and signed in separately.
