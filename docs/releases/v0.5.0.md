# Codex Usage Widget v0.5.0 (local build)

- Enlarged rings and a more readable compact countdown.
- Monitor-aware expansion/drag bounds, including negative monitor origins and mixed DPI. Available working area excludes the taskbar.
- Countdown pauses in the tray or when the window is minimized; reopening computes the current remaining time immediately. Visible compact mode continues counting.
- Tab/Shift+Tab traversal disabled throughout the owned WPF interface; mouse controls and explicit shortcuts remain available.
- Double-click the expanded rings to compact; double-click the compact surface to expand.
- All returned reset expiry dates/times appear in a scrollable list. Partial metadata is labelled, without inventing missing dates.

Both Portable and Lite are built locally. This change does not authorize GitHub publication.
