# Codex Usage Widget 0.1.0

The first Windows release provides a floating full or compact widget for your Codex subscription limits.

- Activity-inspired pink five-hour and lime weekly rings show consumed quota.
- Prominent numbers show remaining percentages; dates show the next reset in local time.
- Updates automatically using the official Codex CLI app-server, with configurable polling and event notifications.
- Includes tray controls, always-on-top, saved position, keyboard shortcuts and optional startup.
- Keeps the last good values during failures and reconnects automatically.
- Russian UI, English documentation and MIT-licensed C# / WPF source.

## Download and run

Download `CodexUsageWidget-win-x64.zip`, extract it, and run `CodexUsageWidget.exe`. The .NET runtime is included. Install the official Codex CLI separately and sign in using `codex login`. You can select the CLI executable in Settings if it is not on `PATH`.

The binary is unsigned. `CodexUsageWidget-win-x64.zip.sha256` provides the archive checksum.

## Notes

This is an independent utility, not an official OpenAI application. Quota percentage is not a count of tokens remaining. Notifications on the widget's app-server connection are not assumed to observe every other Codex client, so polling always remains enabled. Default polling interval is one minute.
