# Codex Usage Widget v0.6.0 (local build)

The reset section follows the supplied row-based reference while preserving the widget's near-black surface, muted dates, outlined gray action buttons and red count badge. Each returned credit has its own action, and expiry includes local date/time and UTC offset.

Every action opens confirmation before spending. The chosen credit is checked again after confirmation; expired or removed credits are rejected. Cancel is the default. A pending reset exposes only recovery of the same persisted attempt, disabling new row actions. The English preview clicks the second row and cancels its matching confirmation without calling the real service.

Both Portable and Lite are prepared locally. No GitHub publication is authorized by this design request.
