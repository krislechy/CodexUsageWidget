# Codex Usage Widget 0.2.0

This release adds earned-reset controls and eight interface languages while retaining the approved Activity-style rings.

## Earned resets

- Displays the server-reported number of available resets and the earliest expiry date.
- Clearly distinguishes a complete expiry list from the earliest **known** expiry when Codex returns partial metadata.
- Offers a reset action in the full widget and tray menu, with explicit confirmation that one reset will be spent.
- Persists the same request before sending it. If a reply is lost, Retry reset safely repeats that attempt, including after restarting the application.
- Re-reads quota values after a definitive reset outcome. Polling never consumes a reset.

## Languages

English is the default. Settings also offers Russian, Ukrainian, Serbian (Cyrillic), French, German, Simplified Chinese and Japanese. Labels, dates, numbers, errors, tray controls, confirmations and accessibility names are localized.

Selecting a language previews it immediately. Save keeps it; Cancel restores the previous language. Old settings without a language field default to English.

## Download and update

Extract `CodexUsageWidget-win-x64.zip` into a new folder and run `CodexUsageWidget.exe`. Exit the previous version from its tray menu first. The .NET runtime is included; the official signed-in Codex CLI is still required. If Start with Windows was enabled for the old executable, disable it there and enable it in the new version after launch.

The executable is unsigned. A SHA-256 checksum is included for the archive.
